## 论文叙事与术语

摘要和引言先呈现表征价值、实验规模与可复现交付；结果保留主对照、消融及实际FPR；结论落到可复用证据和资源条件。所有原始结果与不利比较继续保留。

| 统一术语 | 本文含义 |
| --- | --- |
| Recall@128 | 在最多128个已观察回答token内检出最终不安全回答的比例 |
| 整段FPR | 一条安全回答的全流中至少触发一次告警的比例 |
| 监测隐状态 | 冻结模型读取标注回答所得状态，不是原生成模型轨迹 |
