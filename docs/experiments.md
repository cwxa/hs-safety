# 实验协议与验收

## 1. 研究问题与模型

| 问题 | 对照与观察 |
| --- | --- |
| 隐状态是否提供可用安全信号？ | TF-IDF/LR 与静态隐状态 LR 的最终和流式指标 |
| 时序建模是否有增益？ | 静态 prefix LR 与单向 GRU；动态特征消融 |
| 是否主要依赖危险提问的捷径？ | prompt-only 对照；有足够样本时观察同 prompt 的 safe/unsafe 回答 |
| 检测频率如何影响停止行为？ | stride 4、8、16；每种间隔重新派生特征与校准阈值 |
| 能否泛化到另一来源？ | 固定主数据模型及阈值的 external 测试 |

主模型为冻结 Qwen2.5-0.5B-Instruct、第 6/12/18/24 层、每层训练集 IncrementalPCA 64 维、单向 GRU hidden size 64。主 stride 为 8，基础缓存 stride 为 4。不得用外测标签选择层、超参数、阈值或论文主结果。

## 2. 训练目标

设记录 \(i\) 的最终标签为 \(Y_i\)，有效检查点的等距监督子集为 \(S_i\)，前缀输出为 \(p_{it}\)。默认每条回答最多选择 8 个监督点，并保留终点；GRU 仍按顺序消费完整有效检查点序列。监督损失为：

\[
\mathcal L = \frac{1}{N}\sum_{i=1}^N\frac{1}{|S_i|}
\sum_{t\in S_i}\operatorname{BCE}(p_{it},Y_i).
\]

先对每条回答的监督检查点取平均，再对 batch 内回答取平均，避免长回答因检查点更多而获得额外权重。正负类别权重由训练回答数确定并保存。静态 prefix LR 使用同样的回答权重语义。文本词表和 IDF 仅在训练文本拟合，拟合输入包含终点及选中的训练前缀；推理时只输入已观察前缀。

该目标属于 early sequence/outcome classification。它允许前缀尚未出现明显风险证据时存在不可消除的不确定性；不能将继承的最终标签当作逐 token 人工真值。

## 3. 模型选择、阈值与测试

1. 只用 train 拟合特征预处理与模型。
2. 只用 dev 选择训练轮次与预定候选超参数；保存选择记录。
3. 固定模型后，对 calibration 中每条安全回答计算整条流的最大风险分数，以目标回答级 FPR 校准阈值。主报告使用 5%；其他 FPR 点须说明安全样本量和估计粒度。
4. 风险分数严格大于阈值时触发。阈值 ties、常数分数、无安全样本等边界须测试并有显式处理。
5. 固定模型与阈值后评价 test，再评价 external；不据测试结果反向挑选配置。

逐检查点校准不能代替整回答校准，因为反复检查会增加某次误触发的机会。不同 stride、模型或报警规则须独立完成校准。

## 4. 指标与统计口径

- 分类：AUROC、AUPRC、最终回答分类指标，并注明正类为 unsafe。
- 流式检测：unsafe 回答中任一检查点触发的比例；safe 回答中任一检查点触发的 FPR。
- 停止位置：首次触发时已观察 token 数、占完整回答长度的比例，以及 unsafe 回答可避免继续生成的剩余 token 比例。未检出样本单独说明，不能只统计成功检出的回答而掩盖漏检。
- 资源：峰值显存、缓存体积、特征提取耗时、训练耗时；实测值与估算值区分标注。
- 生成性能：固定生成长度下的监测额外耗时，与提前停止后的总耗时分别报告；计时前后同步 GPU，记录 warm-up 和测量样本数。

没有危险片段起点标注时，不报告相对真实有害起点的延迟。回放中的早停比例是对已知完整回答的离线估计；真实生成可能因采样变化而产生不同回答，不能复用原回答标签。

## 5. 验收与失败处理

| 验收项 | 通过条件 |
| --- | --- |
| 数据 | 无跨主划分 group 重叠；标签映射、过滤与最终数量完整 |
| 因果性 | 更改未来 token 不改变先前检查点；完整/前缀/KV 状态对齐 |
| 特征 | PCA 只拟合 train；位置、mask、差分与 stride 一致 |
| 缓存 | 完整分片可恢复；半写入与身份冲突被检测 |
| 校准 | 使用每条安全回答的最大分数；ties 与极端样本可复现 |
| 生成 | 未通过检查的缓冲不会释放，末尾残留仍被检查 |
| 可复现 | 配置、版本、seed、运行清单、预测和指标均保存 |
| 论文 | 不含编造结果；英文与中文的数值、图表及结论一致 |

失败运行保留错误原因、检查点、已完成产物和耗时。资源不足时先降低提取 batch size；若改变样本范围、骨干、长度或特征设计，应另建配置并重新生成相关缓存和实验标识，不能覆盖后继续沿用旧结果。
