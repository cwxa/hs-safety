# 大数据挖掘与分析：方法主线与关键词

本项目以大模型内容安全为应用场景，以高维序列数据为分析对象，完成“数据准备—特征表示—监督分类—无监督分析—统计评价”的课程实践链路。

| 数据挖掘方法 | 项目中的具体使用 | 对应产物 |
|---|---|---|
| 数据清洗与数据质量分析 | 完整样本长度筛选、缺失／异常记录处理、类别与长度保留率统计 | 数据审计、分布图和划分清单 |
| 去重与分组划分 | 规范化prompt分组、响应模板隔离和文本相似性审计 | 无交叉提示组的训练／开发／校准／测试划分 |
| TF–IDF文本特征提取 | 词与字符n-gram表示，结合逻辑回归构建文本基线 | 仅问题及问题＋回答前缀的分类结果 |
| 增量主成分分析（PCA） | 各层独立降维并白化，仅在训练检查点上拟合 | 紧凑隐状态、保存的投影器及方差保留量 |
| 时序特征工程 | 当前状态、差分、余弦变化和范数变化 | 共享离线／在线动态特征 |
| 监督分类与序列分类 | 逻辑回归、MLP及单向GRU预测最终回答风险 | 基线比较、消融和三种子结果 |
| K均值聚类分析 | 在训练回答终点的完整降维表示中拟合八簇 | 聚类构成图及跨来源群体画像 |
| 二维PCA可视化 | 将训练终点进一步投影至二维 | 表征分布散点图 |
| 统计评价与不确定性分析 | 序列级阈值校准、AUROC／AUPRC、分组配对bootstrap | 检测运行特征和配对区间 |

## 关键词

中文：数据挖掘；主成分分析；特征工程；聚类分析；序列分类；隐状态；大语言模型；流式安全检测。

English: Data mining; principal component analysis; feature engineering; clustering; sequence classification; hidden states; large language models; streaming safety detection.

## 推荐汇报表述

本项目将大语言模型的隐状态视为高维流式序列数据，首先完成清洗、去重与分组划分，随后利用增量PCA进行特征压缩，通过动态特征工程和轻量分类模型挖掘回答风险，并结合K均值聚类与二维PCA分析表征中的群体模式，最终通过独立校准、外部测试及分组统计评价形成完整的数据挖掘实践。

PCA在检测流程中用于高维表示压缩；二维PCA和K均值用于探索性结构分析。聚类对象为回答终点表示，序列动态由GRU及变化特征建模。本文中的数据方法均对应已经运行的实现与工件。
