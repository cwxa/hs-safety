# 论文论证链与证据定位

本文围绕“可见回答前缀如何支持最终安全标签预测”组织论证，依次回答问题、方案和效果。

| 论证环节 | 关键问题 | 解决方式 | 对应证据 |
|---|---|---|---|
| 输入与目标 | 生成尚未结束，当前信息如何用于判断最终风险？ | 因果回放、回答位置对齐、回答均衡弱前缀监督 | 任务定义、因果一致性检查、同题不同回答子集 |
| RQ1 表征与检测器 | 隐状态与时序模型分别带来什么信息？ | 文本、静态、历史均值、GRU及MLP对照 | 主结果、预设配对差值、探索性AUROC与校准敏感性 |
| RQ2 检查频率 | 如何选择检查间隔与特征结构？ | 共享原始缓存，按步长重新计算变化特征 | 消融表、召回曲线、检查点频率分析 |
| RQ3 规模与来源 | 扩大骨干和改变回答来源后表现如何？ | 相同样本的规模对照、冻结阈值的外部评估 | 规模结果、外部结果及逐种子计数区间 |
| 工程可行性 | 能否在本机增量运行？ | 紧凑缓存、共享在线特征、缓冲检查释放 | 实测延迟与显存、KV评分对齐、缓冲与EOS测试 |

摘要呈现研究问题、统一方案与主要数值；引言从任务矛盾推导设计要求；方法逐项落实要求；结果按RQ1—RQ2—RQ3—系统实践展开；结论归纳可执行的模型选择。类别覆盖、前缀标注和原生生成扩展统一在研究展望讨论。

主要成果优势体现在：将隐状态转为可比较的轻量风险特征；通过共同数据、校准与不确定性规则提供模型选择依据；用共享缓存和增量接口将离线研究接入在线实践。各项优势分别由排序对照、召回与实际误报率、以及工程测量支持。

数值以 `results/metrics.json`、`results/review_robustness.json` 和自动生成的论文表格为准。本次仅重组证据和表述，未重新训练或改动正式预测结果。
